07 / THE LEARNING FEEDBACK LOOP

A clear path from task to growth.

1

Create

Instructor sets instructions, deadline, points, and late policy.

2

Submit

Enrolled student submits text and/or an attachment.

3

Review

Course owner assesses work and saves a valid grade plus feedback.

4

Improve

Student views the same result on web or Flutter.

The API enforces deadlines, 20 MB attachment limits, enrollment, and graded-submission locking.

CLASSROOM LMS · FINAL PROJECT08 / 12
08 / SECURITY

Permissions live on the server.

Identity

Bcrypt password hashes.
Signed JWT with expiry.
Persisted, revocable sessions.

Authorization

Role middleware.
Course ownership checks.
Enrollment and submission-owner checks.

Input and transport

Zod validation.
Origin and rate controls.
Protected downloads.
HTTPS required in production.

Web tokens: HTTP-only cookies. Mobile tokens: platform secure storage. No password hashes in API responses.

CLASSROOM LMS · FINAL PROJECT10 / 12
10 / SCOPE AND LIMITATIONS

Focused academic scope.
Clear next steps.

Implemented

Course management, learning materials, assignments, submissions, grades, announcements, profiles, shared API, and student-only Flutter access.

Outside scope / pending

No payments, live video, quizzes, attendance, push alerts, offline submissions, or password-reset email. Android SDK setup and device smoke testing remain; iOS needs macOS/Xcode.

Production also needs HTTPS, managed secrets, backups, monitoring, and release signing.
